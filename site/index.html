Questions

Is it really free?

Yes. Desktop Buddy is free with no ads and no account required.

Windows says “Windows protected your PC”. Is it safe?

That message appears for new apps that haven't built up a download reputation yet. Click More info → Run anyway. You can also install it from the Microsoft Store or with winget install Devwerks.DesktopBuddy.

Will it slow down my computer?

No. The buddy is a small transparent window that animates with CSS, and it pauses itself when you hide it or the PC is idle.

Does it work without internet?

Yes. Tasks, reminders and the buddy all work offline. Internet is only used for optional sync, weather and updates.

What happens to my data?

It stays in a database on your computer. Read the privacy policy for the details.

How do I hide the buddy for a while?

Press Ctrl+Alt+B. Reminders keep working while it's hidden.
